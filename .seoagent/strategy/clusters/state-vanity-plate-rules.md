# Cluster: State Vanity Plate Rules

**Why this cluster first:** the site already has a live availability checker for 8 states (WV, KS, ND, TN, ME, OH, KY, WY) with nothing written about any of them — this is the single clearest gap surfaced by research. Competitors either cover all 50 states thinly (PlateMonitor) or only 11 states with real content (PlateHog, overlapping us only on WV). ME, KY, WY, ND, TN, OH, KS are open territory. Each state page pairs the live checker tool with real content — something no competitor currently does per-state.

**ICP fit:** high — this is exactly the audience already using the checker tool.
**Keyword difficulty:** low-medium (state DMV pages own the raw rules text; content + tool + shareable "recently rejected" hook is the differentiator, not out-ranking the DMV on rules alone).

## Content notes (from context.md)

- Never state a plate is guaranteed available — "appears available" language only, always tell the reader to confirm on the official state DMV site.
- Cite the real official state source for rules (per competitors.md's note — don't try to out-rank the .gov page, cite it).
- A short "recently rejected in [state]" section per state page is a good shareability/linkable-asset hook (per research: this format already gets local-news pickup) — source real examples via WebSearch per state when writing, never invent examples.
